# Chrome Web Store 제출용 설명문

## 짧은 설명
거친 한국어 문장을 상황에 맞는 정중한 메시지로 빠르게 다듬어 주는 Chrome 확장 프로그램입니다.

## 상세 설명
Polite Message Rewriter는 감정적이거나 날카롭게 작성된 한국어 문장을, 실제로 보내기 더 안전한 표현으로 정리해 주는 Chrome 확장 프로그램입니다.

이런 상황에서 유용합니다.
- 상사, 동료, 고객에게 보내는 메시지 톤이 걱정될 때
- 감정적으로 쓴 문장을 한 번 더 다듬고 싶을 때
- 문자, 카카오톡, 이메일 초안을 더 정중하게 정리하고 싶을 때
- 같은 내용이라도 관계와 상황에 맞는 표현으로 바꾸고 싶을 때

주요 기능
- Google 로그인 기반 사용
- 분위기 선택: 보통, 친근하게, 정중하게, 아주 정중하게, 캐주얼하게 등
- 비즈니스형 톤 지원: 보고 요청, 제안서, 일정 변경, 회식 제안, 업무 변경
- 보내는 대상과 본인 역할을 반영한 메시지 다듬기
- 배경 설명(선택) 입력 지원
- 결과 문장 즉시 복사
- 요금제 안내 및 고객 문의 페이지 연결

고객 문의
- 랜딩 페이지의 고객 문의 게시판을 통해 문의를 남길 수 있습니다.
- 문의 내용은 관리자 대시보드와 메일로 함께 전달됩니다.

주의
- 이 확장 프로그램은 문장 표현을 다듬는 도구이며, 사실관계나 법률 판단을 대신하지 않습니다.
- 민감한 계약, 법률, 분쟁 문장은 최종 확인 후 사용해 주세요.
