# 스토어 등록 문구 (한국어 초안)

## 확장 프로그램 이름
Polite Message Rewriter

## 한 줄 요약
감정적인 문장을 상대와 상황에 맞는 정중한 한국어로 빠르게 변환해 주는 메시지 리라이터.

## 상세 설명
Polite Message Rewriter는 거칠거나 감정적인 문장을, 실제 대화/업무 상황에 맞춰 전달력 있는 문장으로 바꿔줍니다.

### 핵심 기능
- 톤 선택: 친근하게 / 정중하게 / 아주 정중하게 / 캐주얼하게 / 공손하지만 단호하게
- 대상 선택: 상사, 동료, 친구, 학부모, 고객, 거래처 등
- 발신자 역할 반영: 예) 담임교사, 팀장, 상담사
- 원문 의미 유지 + 표현 완화
- 결과 즉시 복사

### 사용 예시
- 감정 섞인 컴플레인 문장을 고객 응대 문장으로 정리
- 사내 메시지를 단호하지만 예의 있게 수정
- 관계를 해치지 않으면서 핵심 전달

- Pro: 월 900회

### 데이터 처리 안내
- 사용자가 입력한 원문/설정값을 문장 변환을 위해 서버와 OpenAI API로 전송합니다.
- 결제 기능 사용 시 Stripe를 통해 결제가 처리됩니다.
- 자세한 내용은 개인정보처리방침을 확인해 주세요.
