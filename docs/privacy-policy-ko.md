# 개인정보처리방침 (Polite Message Rewriter)

최종 업데이트: 2026-03-22

Polite Message Rewriter(이하 "서비스")는 사용자가 입력한 문장을 선택한 톤과 상황에 맞춰 재작성하기 위해 필요한 최소한의 정보를 처리합니다.

## 1. 수집 항목
- 필수: 사용자 입력 원문, 선택한 톤/수신자/발신자 역할
- 계정/과금: 이메일, API Key, 결제 상태 정보(구독/결제 이벤트 식별자)
- 결제 처리: 카드 결제 정보는 Stripe가 직접 처리하며 당사는 카드번호 전체를 저장하지 않습니다.

## 2. 이용 목적
- 문장 재작성 기능 제공
- 사용량 집계 및 요금제 제한 적용
- 결제 처리 및 구독 상태 관리
- 장애 대응/악용 방지(로그 기반)

## 3. 제3자 제공/처리 위탁
- OpenAI: 문장 재작성 처리
- Stripe: 결제 및 구독 처리

## 4. 보관 및 파기
- 사용량/결제 이벤트 로그는 서비스 운영 및 정산 목적 범위에서 보관 후 파기합니다.
- 법령상 의무 보관 항목은 관련 법령에 따릅니다.
